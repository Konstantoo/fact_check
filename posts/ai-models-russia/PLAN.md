# План: пост-инфографика «Какие нейросети доступны из России»

Дата среза данных: 18 сентября 2026.

## Шаг 1 — Статичная инфографика (сделано в этой ветке)

1. **Список сервисов** (14 штук), четыре группы: США, Европа, Китай, Россия.
2. **Две модели у каждого**: Frontier (флагман, обычно платный) и Обычная (бесплатный дефолт).
3. **Светофор доступа из РФ**:
   - 🟢 работает без VPN;
   - 🟡 частично: сайт открывается, но регистрация/оплата/нестабильность;
   - 🔴 только через VPN.
4. **Цена в месяц** — базовый платный тариф; про оплату картой РФ — одной строкой в легенде.
5. **Субъективная оценка 1–10** — честно подписана как мнение автора.
6. **Рендер**: `python3 build.py && node render.mjs` → PNG 1080px в 2x, тёмная тема, крупные карточки под телефон.

Файлы:
- `models.md` — таблица-источник, из неё берутся данные для HTML.
- `build.py` — данные и генератор `index.html`, `part1.html`, `part2.html` (мобильная вёрстка карточками).
- `render.mjs` — скрипт рендера PNG через Playwright/Chromium.
- `infographic-1.png` (Запад) и `infographic-2.png` (Китай + РФ) — картинки для поста; `infographic.png` — всё одной простынёй.
- `post.md` — текст для поста в канал.

## Шаг 2 — Интерактивная версия (следующая итерация)

Идея: одна страница, где каждая модель отвечает на один и тот же простой промпт с коротким ответом,
и читатель видит ответы рядом.

1. Выбрать 3–5 промптов: один фактический («Столица Австралии?»), один на русскую грамматику,
   один на актуальность («Кто сейчас президент Франции?»), один бытовой («Что приготовить из яиц и риса?»).
2. Прогнать промпты через все модели (у кого есть API — через API, у остальных — вручную из чата).
   Для российских: GigaChat API и Yandex Cloud (Alice AI / YandexGPT). Для китайских: DeepSeek, Qwen (DashScope),
   Kimi, Z.ai — есть API. Для западных — через VPN.
3. Сохранить ответы в `answers.json`: `{model, prompt, answer, latency_sec, date}`.
4. Страница `interactive.html`: переключатель промпта сверху, карточки моделей с ответами, тот же светофор.
5. Опубликовать как артефакт/страницу и дать ссылку в посте, картинку оставить как превью.

## Шаг 3 — Поддержка актуальности

- Обновлять таблицу раз в месяц: релизы моделей выходят каждые 1–2 недели.
- Проверять доступ из РФ по факту (открыть сайт с российского IP), а не по статьям.

## Заметка про Kimi

Kimi — это Moonshot AI, отдельная компания, а не часть Qwen/Alibaba. Alibaba инвестировала в Moonshot,
но модели и чат у них независимые. В таблице Kimi стоит отдельной строкой.
