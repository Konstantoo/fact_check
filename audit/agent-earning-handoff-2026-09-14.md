# Хендофф: заработок агента `xboss` — 14.09.2026

> Восстановлено текстом из локальной сессии (оригинал на Маке в git не отправлялся).
> В репозитории намеренно не хранятся: имя владельца, адреса кошельков, ключи,
> параметры хозяйства. Владелец обозначается как «владелец».

## 1. Задача
Агент `xboss` зарабатывает на площадках для AI-агентов. Выплаты — USDC в сети Base.
Сначала вернуть единицы долларов, лучше — старт постоянного дохода.
**Заработок должен окупать токены Anthropic**: работа агента не бесплатна.

## 2. Разведка 14.09 (только чтение, 13 веб-запросов)
- **Virtuals ACP** — USDC на Base, эскроу по контракту, провайдеру 80 %
  (whitepaper.virtuals.io/about-virtuals/agent-commerce-protocol-acp).
  Нужны кошелёк агента + подпись, регистрация в Agent Registry. KYC человека не найден.
- **x402** — оплата USDC за вызов своего платного API; вход = поднять и хостить эндпоинт.
  Цифры KPMG за февраль 2026 (161,32 млн транзакций, 43,57 млн $) — только вторичные пересказы.
  По TRM Labs / Chainalysis большая часть объёма x402 — не торговля между агентами.
- **Algora** — $50–2 500 за GitHub-баунти через Stripe Express; нужен KYC человека
  (конфликт с рамкой), 8–158 конкурентов на баунти.
- **dealwork.ai**, **opentask.ai**, **ugig.net** — заявлена USDC-эскроу, выплаты подтверждены
  только статистикой самих площадок *[не подтверждено]*.
- **OKX Agent Marketplace** — стейблкоины, вероятен KYC.
- Отброшено: swarmmemo, 1f916, getpostingboard, 4claw, aicq (платной работы нет),
  Moltbook (карма), Recall (конкурс), MuleRun (бонусы-приманки), Toku (продаж нет),
  Circle marketplace (вход через форму с данными человека).
- Риск: honeypot-баунти, вытягивающие у агента системный промпт и конфиг.

**Вывод:** разовой подработки с доказанными выплатами нет; доказанно платят ACP и x402,
но это маленький продакшн-проект.

## 3. Рамка (MUST)
- На площадках ничего о владельце, минимум о системе (модель, ОС, каналы, клиенты,
  числа хозяйства — нельзя); имя агента `xboss` / `xboss-xoxomo`.
- Регистрация, отправка работы, кошелёк агента, любые траты — **только по явному GO
  владельца на каждый шаг**.
- Имя владельца на площадках не светится; KYC на его имя — только его отдельное решение.
- Ключи: у агента нет доступа к seed и приватному ключу владельца; для выплат нужен
  только публичный адрес. Для ACP агенту нужен свой подписывающий кошелёк, отдельный
  от кошелька выплат; где хранить его ключ — решает владелец.
- Разведки с бюджетом запросов, минимум токенов.

## 4. Кошелёк
EVM-кошелька под Base у владельца не было — заводит MetaMask. Публичный адрес
(`0x…`, 42 символа) сообщается в чат; годится для Base без изменений.
**В репозиторий адрес не коммитится.**

## 5. Решения за владельцем
1. Публичный адрес USDC (Base).
2. Первая разведка: **(а)** реальны ли выплаты на dealwork.ai / opentask.ai / ugig.net —
   *рекомендация*; (б) есть ли в ACP builder-гайде спрос на наши навыки (код, исследования,
   тексты RU/EN, факт-чек), а не только трейдинг и арт; (в) сразу строить сервис x402.
3. KYC на имя владельца: да или нет.
4. Лимит расходов до первого заработка.
5. Где хранить ключ кошелька агента для ACP.

## 6. Первый шаг
По решению (2) одна разведка, ≤ 15 веб-запросов, только чтение, без регистраций.
Итог: платит или нет (доказательство выплат с датой), что нужно для входа,
сколько токенов на задачу против оплаты, конфликт с рамкой.
